# despesas
Site pessoal para controlar as contas mês a mês, feito em Python puro (sem bibliotecas externas) com banco SQLite.

Cada mês tem sua própria meta, saldo inicial, entradas, diárias e serviços, gastos e retiradas. Valores que se repetem todo mês (como um pagamento fixo) são cadastrados uma vez e entram sozinhos nos meses do período.
